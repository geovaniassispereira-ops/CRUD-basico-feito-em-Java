# CRUD-basico-feito-em-Java
CRUD simples em Java com framework Spring Boot.
Aplicação de um sistema de cadastro de livros com todos os métodos de um CRUD básico, feito na linguagem Java no IntelliJ com o framework Spring Boot.

Como iniciar:
- Rodar a aplicação.
- Acessar: http://localhost:8080/livros

Endpoints:
GET /livros
POST /livros
PUT /livros/{id}
DELETE /livros/{id}
